# LapLend – Offline Laptop Rental & Inventory Management System

## Project Overview

LapLend is an offline laptop rental and inventory management system developed using React Native and Expo.

The application helps users manage laptop inventory, browse available laptops, handle rental requests, and track rental records.

## Main Features

- View the dashboard and laptop inventory.
- Browse available laptops.
- View individual laptop details.
- Submit laptop rental requests.
- Manage laptop records.
- Track rental information.
- Store data locally using SQLite.

## Technologies Used

- React Native
- Expo
- JavaScript
- SQLite
- React Navigation

## Database

LapLend uses a local SQLite database to store laptop inventory and rental information.

The application is designed to work offline without requiring a continuous internet connection.
